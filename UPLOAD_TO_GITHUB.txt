WUDROID 0.0.4 EXPERIMENTAL

This ZIP is laid out for the ROOT of the Wudroid repository.
After extraction, the folder you upload must directly contain:

.github/
app/
branding/
wudroid-overlay/
gradle/
README.md
THIRD_PARTY_NOTICES.md
build.gradle
gradlew
settings.gradle

GitHub Actions will clone the Cemu Android engine recursively during the build and produce an installable experimental APK.
