# Wudroid 0.1.1 — Gamepad Editor Test8

Continuation of the RobustFix2 build that compiled successfully.

Changes only the touch gamepad editor:

- The editor panel has a centered **▲** button at its bottom.
- Pressing it hides the panel upward with a smooth slide/fade animation.
- While hidden, only a centered **▼** button remains at the top.
- **Transparency** remains a global gamepad setting.
- **Size** is now per-control.
- Tap a gamepad control to select it; the selected control gets a translucent cyan highlight.
- The Size slider affects only that selected control.
- Controls remain draggable for position editing.
- Reset and Concluir are preserved.
- In-game left/right menus are intentionally untouched.
