# Wudroid 0.1.1 - Full Controller UI Test1

This test replaces the visible Controller 1 configuration layout rather than adding a small keyboard/mouse card to the old page.

- Keeps the main Controls entry in Settings.
- Rebuilds the Player controller page around the native Cemu input mapper.
- Keyboard + mouse settings are integrated at the top of the controller page.
- A/B/X/Y, D-pad, sticks and triggers remain mapped through Cemu's native per-input popup.
- Mouse is reserved for right-stick emulation when enabled.
- Existing gamepad controller types and mapping dialogs remain available.
