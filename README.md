# Wudroid Touch Layout v1.1

Aumenta o GamePad virtual em cerca de 30–45%:
- sticks maiores
- D-pad maior
- ABXY maiores
- L3/R3 maiores
- ZL/L/ZR/R maiores
- +/- maiores
- transparência padrão 128/255

O novo marcador `layout_v1_1_applied` força a reaplicação automática do preset na primeira abertura desta build.
