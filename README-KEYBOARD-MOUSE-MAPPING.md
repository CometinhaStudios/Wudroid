# Wudroid 0.1.1 - Keyboard + Mouse Mapping Test1

This test moves keyboard mapping into Cemu's real Controller / Player mapping UI.

- Tap A/B/X/Y, d-pad, left-stick directions, triggers, etc. and press a keyboard key.
- Keyboard mappings are handled by Cemu's native input mapper instead of hard-coded WASD.
- Mouse movement is reserved for the right analog stick.
- Added mouse sensitivity, pointer capture and invert X/Y options.
- Existing LibraryFix and ShaderPreload patches are preserved.
