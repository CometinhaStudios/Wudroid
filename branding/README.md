# Wudroid Branding

Ícone oficial desta base:

- quadrado azul com cantos arredondados;
- `W` branco estilizado;
- ponto branco central;
- sem fundo branco externo no PNG;
- inclui versão vetorial SVG e PNG 512/1024.

No Android, o projeto possui:

- ícones PNG de fallback (`mipmap-*`);
- ícone adaptativo Android 8+ (`mipmap-anydpi-v26`);
- `roundIcon` configurado;
- splash Android 12+ usando o mesmo launcher icon.
