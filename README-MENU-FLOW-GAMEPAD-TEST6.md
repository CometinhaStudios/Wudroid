# Wudroid 0.1.1 — Menu Flow + Gamepad Test6

- Remove a captura global de swipe da tela do jogo para não interferir no controle touch.
- Botão Voltar pausa a emulação e abre o menu principal.
- Swipe para a esquerda dentro do menu principal abre Quick Settings.
- Swipe para a direita dentro do Quick Settings volta ao menu principal.
- Transição usa animações simultâneas dos dois drawers.
- Quick Settings usa os mesmos cards, cores e tipografia do menu principal Wudroid.
- InputOverlaySurfaceView real do Cemu amplia controles touch em 1.60x no modo paisagem e 1.35x no retrato, inclusive layouts já salvos.
